# Decision record: the JAX and Cython backends

Date: 2026-11-20. Roadmap item B1 (`docs/superpowers/specs/2026-06-12-cenop-roadmap-design.md`).

## JAX: deprecated, to be removed in a later release

**Decision.** The JAX backend (`use_jax=True`) is deprecated as of 2026-11-20. The code and
its tests stay for now. Creating a population with `use_jax=True` raises a `FutureWarning`.
Model changes are no longer ported to it. Removal is a separate, later step.

**Context.**

- **Speed.** On real landscapes JAX was about 5 times slower per tick than Numba when last
  measured (2026-11-11, 2000 animals: about 70 ms against 13 ms before the land-avoidance
  port; Numba about 7 ms). It was not re-measured for this decision.
- **Coverage.** It cannot run the `InnerDanishWaters` or `Undirected` dispersal modes; it
  raises an error. `InnerDanishWaters` is the mode DEPONS prescribes for Kattegat and the
  one the reference baselines use.
- **Validation.** The comparison with DEPONS 3.2 (`docs/validation/A2-parity-report.md`)
  covers the default NumPy/Numba path only. JAX runs float32 with its own random stream and
  is tested for per-backend determinism and for statistical agreement, not identity.
- **Cost.** About 1,700 lines of kernels (`jax_kernels.py`, `tick_jax.py`) and 2,650 lines of tests. Every model change in
  November 2026 (daily step, mortality, dispersal, land avoidance) had to be made twice.
- **Tests.** On the development machine (2 GB GPU shared with the desktop) the JAX tests fail
  intermittently with out-of-memory errors.

**Options considered.**

| Option | Outcome |
|---|---|
| Invest: GPU batching for large populations, port the missing dispersal modes | Rejected. No current use needs populations large enough to repay it. |
| Remove now | Rejected for now. Not reversible except from git history; a deprecation period costs little. |
| Deprecate now, remove later | Chosen. |

**What deprecation means in practice.**

- `use_jax` stays `False` by default and keeps working where it worked before.
- A model change that touches the tick no longer needs a JAX port. If the JAX tests then
  fail, the affected test is removed or the backend is made to raise for that feature; the
  backend is not extended.
- Removal deletes `src/cenop/optimizations/jax_kernels.py` and `tick_jax.py`, the JAX branch of
  `PorpoisePopulation.step`, the `use_jax` parameter and `tests/test_jax_tick.py`.

## Cython: kept, repaired

**Decision.** The fused Cython kernel stays. It was repaired in July 2026 (float64 food grid,
move arithmetic, seeded mortality) and its equivalence test is a green guard
(`tests/test_backend_equivalence.py::test_cython_postcrw_matches_reference`).

**Scope.** It is used on homogeneous landscapes with communication off and no energy module;
real landscapes always take the NumPy/Numba path. It received the daily-step changes of
2026-11-19.
