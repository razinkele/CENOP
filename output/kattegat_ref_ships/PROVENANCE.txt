SUPERSEDES the prior baseline (commit 27824e1, then 7232419), which used a flat
class-based ship source level (~170-175 dB for all ships) and let ship deterrence
deactivate dispersal.

This baseline reflects the Round-2 parity fixes:
  - JOMOPANS per-vessel source level: ship SL now depends on the real vessel type,
    length, and per-buoy speed read from ships.json (band 12). Realistic SLs are
    lower than the old flat 170 dB for most classes, so fewer porpoises clear the
    Tships=80 dB gate at range -> fewer deterrence events than the prior baseline.
  - Turbine-only dispersal deactivation: ship deterrence no longer deactivates
    dispersal (DEPONS deactivates only for turbine/sound-source deterrence). This
    scenario has no turbines, so dispersal is unaffected by the ships here.
  - is_disturbed reporting threshold lowered 0.1 -> 0.01 (captures ship deterrence).
