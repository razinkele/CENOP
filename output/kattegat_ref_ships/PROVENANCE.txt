SUPERSEDES the prior baseline (commit 3a87975, 2026-07-09, code 5e11846). Behaviour
changes since then, all aimed at DEPONS 3.2 parity (details in CHANGELOG [Unreleased]
and docs/superpowers/specs/2026-11-10-phantom-food-investigation.md):

  - Phantom food removed: the eat kernels no longer top up empty cells to 0.01
    (eba75f9). This was what kept the old baselines' population near 2000.
  - communication_enabled now defaults to False (864d0c9).
  - PSM-Type2 dispersal ported to DEPONS (D1-D14): validated targets and target
    heading, three-drop trigger on 3-d.p. daily means, psm_angle turn on path length,
    per-step look-ahead stops, path-length completion.
  - Land avoidance ported to DEPONS (D15): checkDepth look-ahead of presMov cells
    and avoidLand before heading composition, reflection only after, beh-6 turn-back;
    plus the D9 first-call not-enough-water dispersal stop.

These change the seeded RNG stream and the population trajectory; outputs are not
comparable with the previous baseline.

Run summary:
  - 2 yr (34,560 ticks), N=2000; population 2000 -> 314 (day 180) -> 154 (day 360)
    -> 135 (day 540) -> 114 (day 720). The previous baseline stayed near 2000 (1998).
  - 37,091 nonzero deter_strength records, max 0.3168 (previous: 183,932, max 0.3163).
    The record count falls with the population; the peak is unchanged.
  - The decline matches the other regenerated variants (undisturbed 5 yr: 2000 -> 55;
    turbines Kattegat-test 2 yr: 2000 -> 104). data/Kattegat is the v3.0 landscape,
    which has less food than the v3.2 landscape used for the DEPONS Java comparisons,
    so CENOP's baselines fall faster early (undisturbed: 994 at day 63) than the
    v3.2 runs reported in the investigation spec.

Committed files are the compact DEPONS-format outputs (Population.txt, Energy.txt,
Mortality.txt) plus this PROVENANCE.txt. The heavy per-individual / per-event files
(PorpoiseStatistics.txt, Dispersal.txt) are gitignored and regenerable via the
command above.
