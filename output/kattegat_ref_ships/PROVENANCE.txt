SUPERSEDES the prior baseline (commit 8e198c1, Ship-Deterrence Parity Round 2),
which evaluated ship deterrence at a SINGLE end-of-tick ship position.

This baseline reflects the sub-tick interpolation change (DEPONS Ship.java
interpolateStep parity): ship deterrence is now evaluated at 30 interpolated ship
positions along each ship's within-tick swept path (start-of-tick -> end-of-tick).
Per porpoise, per sub-step slot, the maximum-received-level ship wins
(ShipDeterrence.recordStep); the 30 slots are summed into the per-tick deterrence
vector (deterrenceVtX/Y). Because each sub-step draws its own reaction Bernoulli,
deterrence is integrated over the ship's passage, so per-tick magnitudes and the
number of nonzero deterrence events are substantially higher than the prior
single-position baseline. The scalar test-only aggregator's transmission loss was
also made consistent with the production path via a shared received-level helper.

Run summary:
  - 2 yr (34,560 ticks), N=2000, population stable (2000 -> 1998; min 1987, max 2000)
  - 188,072 nonzero deter_strength records, max 0.3168
    (compare: prior single-position baseline had 10,123 nonzero, max 0.0409
     -> ~18.6x more events, ~7.7x larger peak, as expected from swept-path integration)
  - Population stability confirms the increased deterrence is not pathological
    over-deterrence.
